# Ultrapkg philosophy

Flax system is built around a simple idea: do less, but do it well.

This matters for package handling. Package installers should not be giant, noisy, and hard to reason about. They should be clear, modular, and stable.

## Core principles

- simplicity over spectacle
- hierarchy over chaos
- transparency over hidden magic
- security over convenience
- small tools that do one job well

## Why this matters

A package manager is part of the system foundation. If it is confusing, large, or fragile, it makes the whole desktop feel messy.

Ultrapkg aims to be the opposite: obvious structure, predictable behavior, and a small enough footprint to fit XFCE and Flax system design.
